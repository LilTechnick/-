# Expense Tracker (Трекер расходов)

Консольное приложение на Python для учета и контроля личных ежедневных трат. Программа позволяет записывать расходы по категориям, просматривать историю операций и следить за балансом без необходимости подключения к интернету.

## Возможности

* Фиксация расхода: ввод суммы, выбор категории и добавление комментария.
* Просмотр истории: вывод полного списка совершенных операций с деталями.
* Подсчет статистики: мгновенный расчет суммарных расходов за все время.
* Автономное сохранение: запись данных в локальный файл (информация сохраняется после закрытия программы).
* Простое текстовое меню: управление через ввод номеров команд в терминале.

## Требования

* **Язык программирования:** Python версии 3.8 или выше.
* **База данных:** отдельная СУБД не требуется (хранение организовано в локальном файле формата CSV / JSON).
* **Аппаратные требования:** любая рабочая станция или ноутбук (Windows, Linux, macOS), минимум 512 МБ оперативной памяти и от 50 МБ свободного места на диске.

## Установка

1. Склонируйте репозиторий с проектом:
   ```bash
   git clone https://github.com/krishjais783/expense-tracker-python.git
   ```

2. Перейдите в корневой каталог проекта:
   ```bash
   cd expense-tracker-python
   ```

3. (Рекомендуется) Создайте и активируйте изолированное виртуальное окружение:
   * Windows:
     ```cmd
     python -m venv venv
     venv\Scripts\activate
     ```
   * macOS / Linux:
     ```python
     python3 -m venv venv
     source venv/bin/activate
     ```

4. Установите зависимости проекта (при наличии файла requirements.txt):
   ```bash
   pip install -r requirements.txt
   ```
   *(Если файл зависимостей отсутствует, используются только встроенные модули стандартной библиотеки Python).*

## Пример использования

Запустите программу через командную строку:
```bash
python main.py
```

После старта отобразится текстовый интерфейс. Пример типового сценария:

```text
=== ТРЕКЕР РАСХОДОВ ===
1. Добавить новый расход
2. Посмотреть историю расходов
3. Посчитать общую сумму
4. Выйти из программы

Выберите действие (1-4): 1
Введите сумму трат: 350
Введите категорию (продукты, транспорт, кафе и т.д.): продукты
Краткое примечание: Покупка молока и хлеба
[OK] Запись успешно добавлена.

Выберите действие (1-4): 3
Общая сумма расходов: 350.00 руб.

Выберите действие (1-4): 4
Сессия завершена. Данные сохранены.
```
